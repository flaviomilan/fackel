## 🎯 Objective

**Fackel** (German for Torch) is an OSINT (Open Source Intelligence) analysis tool that uses the power of an autonomous AI agent (based on LangChain and LLMs like GPT) to conduct investigations on a given domain. 

The goal is to automate the process of collecting, correlating, and analyzing public information, transforming raw data into a cohesive and actionable intelligence report.

## ✨ Features

- **Agent Architecture:** Utilizes a LangChain agent to plan and execute tasks autonomously.
- **Passive Collection:** Gathers information from public sources without directly interacting with the target (WHOIS, VirusTotal, DNSDumpster, Google, etc.).
- **Active Scan (Optional):** Capable of performing active network scans (Nmap) for a deeper analysis, controlled by a security flag.
- **Comprehensive Enumeration:** Discovers subdomains, hosts, IP addresses, services, and open ports.
- **People and Company Analysis:** Searches for employees on LinkedIn, analyzes professional profiles, and job openings to identify technologies and organizational structure.
- **Final Report:** Consolidates all information into a final report generated by the AI.

## 🛠️ How It Works

Fackel operates with a central agent that receives an objective (e.g., "analyze the domain `example.com`"). The agent has access to a set of "tools," and based on its internal methodology (defined in the prompt), it decides which tool to use at each step, analyzes the result, and plans the next step until the investigation is complete.

### Available Tools

The agent has access to the following tools:

#### Passive (Default)
- **whois_lookup:** Collects domain registration data.
- **virustotal_subdomain_enum:** Finds subdomains via VirusTotal API.
- **dnsdumpster_lookup:** Searches for subdomains and DNS records (great alternative without API key).
- **shodan_lookup:** Searches for information about IPs and services on Shodan.
- **censys_lookup:** Searches for hosts and infrastructure information on Censys.
- **search_linkedin_for_employees:** Finds company employees on LinkedIn via SerpApi.
- **analyze_professional_profile:** Analyzes a professional's profile based on public searches.
- **analyze_email:** Checks an email's exposure in data breaches.
- **job_search:** Searches for job openings to identify technologies.
- **duckduckgo_lookup:** Performs generic web searches.
- **serp_search:** Performs advanced Google searches via SerpApi.
- **extract_webpage_content:** Extracts text content from a web page.

#### Active (Requires `--active-scan` Flag)
- **nmap_port_scan:** Performs a port and service scan (`-sV -T4`) on a specific host.

## 🚀 Installation

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/flaviomilan/fackel.git
    cd fackel
    ```

2.  **Create a Virtual Environment:**
    ```bash
    python3 -m venv .venv
    source .venv/bin/activate
    ```

3.  **Install the Dependencies:**
    ```bash
    pip install -e .
    ```

4.  **(Optional) Install Nmap:**
    To use the active scan, you need to have Nmap installed on your system.
    ```bash
    # On Debian/Ubuntu
    sudo apt-get update && sudo apt-get install nmap
    ```

## ⚙️ Configuration

Before running, create a `.env` file in the project's root and add your API keys. Fackel will look for the keys in this file.

```env
# Required for the AI Agent
OPENAI_API_KEY="sk-..."

# Required for advanced and employee searches
SERPAPI_API_KEY="..."

# Required for subdomain enumeration via VirusTotal
VIRUSTOTAL_API_KEY="..."

# Keys for infrastructure tools (optional)
SHODAN_API_KEY="..."
CENSYS_API_ID="..."
CENSYS_API_SECRET="..."
```

## ⚡ Usage

Usage is via the command line.

**Example of Standard Analysis (Passive Only):**
```bash
python3 src/main.py yourdomain.com
```

**Example of Analysis with Active Scan:**

> ⚠️ **WARNING:** Use this option with extreme caution and only on targets for which you have explicit permission to perform network scans.

```bash
python3 src/main.py yourdomain.com --active-scan
```
